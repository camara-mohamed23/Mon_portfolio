Diabetes Risk Prediction AI

  1. Accueil
  2. Détail du projet

Travail effectué

  • DiabetesCare AI est une plateforme de Data Science et de Machine Learning dédiée à l’analyse des facteurs associés au risque de diabète à partir d’un dataset de 50 000 patients et 41 variables. Le projet combine une chaîne complète de traitement des données, plusieurs modèles de Machine Learning, une API REST avec FastAPI et une interface web premium développée avec Streamlit. Objectif L’objectif est de construire une solution capable d’analyser les caractéristiques physiologiques, biologiques, cardiovasculaires et comportementales d’un patient afin d’estimer une catégorie de risque : Low Moderate High Le système est conçu comme un prototype de support à l’analyse clinique et à la recherche, et non comme un outil de diagnostic médical. .
  • Dataset : 50 000 patients · 41 variables Type : Classification multiclasse (Low, Moderate, High)
  • Approche:
    • Nettoyage et contrôle de la qualité des données
    • Suppression des variables inutiles et potentiellement génératrices de fuite de données
    • Gestion des valeurs manquantes
    • Standardisation des variables numériques
    • Encodage des variables catégorielles
    • Encodage de la variable cible
    • Séparation Train/Test 80/20
    • Cross-Validation
    • Comparaison de plusieurs algorithmes
  • Backend:
    • L'API FastAPI expose le modèle Machine Learning sous forme de service REST.
    • Elle permet notamment de :
    • recevoir les données d’un patient ;
      • effectuer la prédiction ;
    • retourner la catégorie de risque ;
    • retourner les probabilités associées aux différentes catégories ;
    • fournir les informations sur le modèle ;
    • vérifier l’état de fonctionnement de l’API.

Modèles utilisés

  • Modèles : Logistic Regression
  • Random Forest
  • Gradient Boosting
  • XGBoost
